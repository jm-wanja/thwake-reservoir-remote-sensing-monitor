# Glossary

| Term | Plain-language meaning |
|------|------------------------|
| **AEV curve** | Area–Elevation–Volume curve: a lookup table built from the empty valley's terrain that says, for each water level, how big the lake is and how much water it holds. |
| **AOI** | Area of interest — the polygon we analyse. |
| **Backscatter (dB)** | How much radar signal bounces back to the satellite. Calm water reflects it away, so it looks dark (low dB). |
| **DEM** | Digital Elevation Model — a map of ground height. |
| **Earth Engine (GEE)** | Google's free (for non-commercial use) cloud platform for analysing satellite data. |
| **FSL** | Full supply level — the normal maximum water level of the reservoir. |
| **Impoundment** | Starting to hold back water behind the dam so the reservoir fills. |
| **Max-extent mask** | All land low enough (below FSL) and connected to the dam that could become reservoir. |
| **MCM** | Million cubic metres (1 MCM = 1,000,000 m³ = 1 billion litres). |
| **MNDWI / NDWI** | Water indices from satellite colour bands; high values = water. |
| **NDCI** | Index sensitive to chlorophyll (algae) in water. |
| **NDTI** | Index sensitive to turbidity (muddy, cloudy water). |
| **NDVI** | Vegetation greenness index — used to spot irrigated crops. |
| **Otsu threshold** | An automatic way to pick the cut-off between "water" and "land" for each image. |
| **Sentinel-1** | European radar satellites — see through clouds. |
| **Sentinel-2** | European optical satellites — like a camera, 10 m detail, blocked by clouds. |
| **Speckle** | Grainy noise in radar images; filtered before analysis. |
| **Turbidity** | Cloudiness of water from suspended mud/particles. |
